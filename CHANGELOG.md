## [0.1.0] - 2026-11-03

### Added
- Initial release of Stellar Toolkit
- Account management utilities (keypair generation, balance checking)
- Payment operations (simple and path payments)
- Trustline management (add/remove trustlines)
- Asset utilities (create, format assets)
- Network utilities (automatic network detection)
- Full TypeScript support with type definitions
- Comprehensive error handling
- Jest test suite with example tests
- ESLint and Prettier configuration
- Complete documentation in README

### Core Features
- `AccountManager`: Account operations
- `PaymentManager`: Payment transactions
- `TrustlineManager`: Trustline operations
- Network abstraction for testnet/mainnet

### Developer Experience
- Simple, intuitive API
- Full type safety
- Helpful error messages
- Extensive documentation
